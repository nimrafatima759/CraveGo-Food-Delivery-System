# CraveGo - Food Delivery System

## About
CraveGo is a full-stack food delivery web application developed as part of my Full Stack Web Development internship at Sqrock IT Solutions.

## Features
- User Registration & Login
- Session Authentication
- Restaurant Listing
- Food Menu
- Categories
- Search/Filtering
- Shopping Cart
- Checkout
- Order Placement
- Order Confirmation
- My Orders
- REST-style PHP APIs
- MySQL Database
- Responsive UI

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
- Fetch API
- Font Awesome
- Google Fonts

## Database
The application uses MySQL for:
- Users
- Restaurants
- Categories
- Foods
- Orders
- Order Items

api/

## How to Run Locally

1. Install XAMPP
2. Start Apache and MySQL
3. Place project inside htdocs
4. Create database `cravego_db`
5. Import the database tables
6. Open:

http://localhost/cravego/

## Learning Outcome

This project helped me gain practical experience in full-stack web development, including frontend development, PHP backend integration, MySQL database management, APIs, authentication, sessions and order processing.
